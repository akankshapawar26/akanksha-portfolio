# Photo Marquee Assets

Upload your 17 marquee photos into this folder (`/public/marquee/`).

### Recommended Naming:
- `photo-1.jpg` (or `photo-1.png`, `1.jpg`, `marquee-1.jpg`, etc.)
- `photo-2.jpg`
- `photo-3.jpg`
- ... up to
- `photo-17.jpg`

You can upload `.jpg`, `.jpeg`, `.png`, or `.webp` files here!
